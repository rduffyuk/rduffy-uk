What these values mean & sources

RAM is the maximum of 50,857 retained cgroup memory.current observations (median 33.9976 GiB), including charged file cache; not RSS or a continuous peak. The 8.00 GiB pinned expert copy and 3.09 GiB full KV copy reported at startup are included functional components, not additional to the footprint. File and anonymous categories are not mapped to those components. KV is attention state, not literal text; hybrid models also have other sequence state. The 38 GiB value was a configured ceiling, not observed use. GPU is a startup checkpoint; it is not coincident with the RAM sampled maximum. SSD backing and copies in RAM/GPU overlap: do not split or subtract the file size across pools. GPU KV payload is estimated from 3.09 × 32,768 / 262,144 = 0.38625 GiB. GPU residual is not detailed component attribution. Profile: 262,144 tokens, 32,768 GPU-resident cells per QSA layer, int8 KV.
