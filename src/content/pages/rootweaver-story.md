---
title: The Rootweaver Story
---

Rootweaver started with a single conversation on September 11, 2025. I had an Obsidian vault full of notes and no way to search them semantically. Claude Code and I indexed the vault into ChromaDB, and the first search worked.

That was the founding conversation. Everything since has been organic growth — each day building on the last, each feature emerging from a real need. From a local Python script to a production Kubernetes cluster with 29 MCP tools, multi-agent RAG search, knowledge graphs, and a full observability stack.

The Journey Map on this site shows that evolution in real time. Every node is a component that exists in production. Every edge is a real connection. Every milestone is a moment where the platform grew.
