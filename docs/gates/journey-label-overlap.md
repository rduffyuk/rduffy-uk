**Goal**: In the `/journey` 3D force-graph, node text labels overlap and become
unreadable where nodes cluster (worst in the `core` group, ~10 seed nodes packed
together). Make labels legible — reduce/eliminate overlap — without removing nodes.

**Jira**: n/a (rduffy-uk personal site; not VW-tracked).

**Files in scope**:
- `src/components/journey/GraphScene.tsx` — `layoutNodes()` group clustering (centers/spread).
- `src/components/journey/NodeMesh.tsx` — the `<Text>` label rendering.
- (Allowed if needed) `src/components/journey/JourneyScrollytelling.tsx` — passes `dark` + currentIndex.
- Do NOT touch `src/data/journey-data.json` (generated by scripts/build-journey.mjs) or `scripts/build-journey.mjs`.

**Acceptance criteria**:
1. Labels in dense clusters no longer visually overlap into illegible text. Approaches allowed
   (pick one or combine): widen cluster spread / push clusters apart; fade or hide a node's
   `<Text>` by camera distance (use `useThree`/`useFrame` camera distance, billboard already implicit
   via drei `<Text>`); scale label opacity by depth; shorten/clip long labels. Keep all nodes present.
2. MUST preserve existing behaviour: theme-awareness via the `dark` prop (label colour
   `dark ? "#f1f5f9" : "#21262e"`), the `OrbitControls autoRotate`, the per-node spin
   (`spinSeed`), the scale-in animation, and node click → DetailCard.
3. No new runtime deps. react-three-fiber / @react-three/drei / three only.
4. `pnpm build` succeeds and emits the `/journey` page (44 pages total).
